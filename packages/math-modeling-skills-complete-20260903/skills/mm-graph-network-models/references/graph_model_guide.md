# 图模型选择与核验

| 问题 | 首选方法 | 关键前提 | 必做核验 |
|---|---|---|---|
| 非负边权最短路 | Dijkstra | 边权非负 | 路径边权逐项求和 |
| 含负权边最短路 | Bellman-Ford | 无可达负环 | 负环检测 |
| 全源最短路 | Floyd-Warshall | 中小规模图 | 与若干单源结果交叉检查 |
| 容量瓶颈 | 最大流/最小割 | 容量非负 | 流守恒、容量、割容量 |
| 连接成本最低 | 最小生成树 | 无向连通图 | 边数为 n-1、连通、无环 |
| 任务—资源配对 | 二分图匹配 | 两类节点与合法边明确 | 匹配唯一性与未匹配原因 |
| 时变传播 | 时间展开图/事件模拟 | 更新时间有序 | 每次更新前后快照 |

建模时先保存 `nodes.csv` 与 `edges.csv`，其中至少包含节点 ID、起点、终点、方向、权重、单位和来源。若边权由公式计算，还要保存原始字段。优化问题可进一步接入 NetworkX、SciPy 或 OR-Tools，但引用第三方库不等于验证了现实假设。

国奖案例启示：2020 B 题先把地图压缩成决策网络再做动态规划；2025 D 类问题需要在边状态变化后重新计算传播与路径。两者都要求把“图结构”和“状态转移”分开保存。
