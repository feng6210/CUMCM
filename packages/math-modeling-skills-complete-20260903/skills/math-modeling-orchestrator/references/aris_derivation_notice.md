# ARIS 派生内容与许可证说明

本数学建模 Skill 包复制并改造了 Auto Claude Code Research in Sleep (ARIS) 的通用实验与论文方法。来源提交：`94d8093ed21d20a790830318190095b9f5036ce8`。

已本地化的内容包括：证据存在性预检查、实验完整性原则、输出版本与清单、写作的结论—证据映射、论文数字审计、引用审计以及确定性 SVG 图形渲染。

ARIS 原始仓库采用 MIT License。完整许可证见 [ARIS_MIT_LICENSE.txt](aris-derived/ARIS_MIT_LICENSE.txt)。本包不在运行时访问 ARIS、GitHub 或远程仓库。

未继承的 ARIS 行为包括自动 Git 操作、SSH/GPU 队列、W&B、ML 会议页数、固定种子数和自动停止训练。
