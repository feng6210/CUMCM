# 机制驱动的组合模型与创新模式

以下模式来自本地资料的结构蒸馏，并经过反例筛选。它们只是候选路线；进入求解前仍须生成创新证据卡并获得用户批准。

## 1. 残差分解与二阶段修正

适用：基线能捕捉主趋势，但滚动验证残差仍有可学习结构。

链路：`简单基线预测 → 仅用训练期/折外残差训练修正器 → 合成预测 → 与基线同切分比较`。

证据：残差自相关或条件结构、严格时间滚动验证、基线与组合模型的同窗误差、修正器消融、预测区间。禁止用测试期真实值产生残差再训练修正器。

## 2. 代理模型辅助的昂贵优化

适用：一次真实评估成本高，决策维度与预算可管理，并能获得不确定性或可信误差估计。

链路：`初始设计 → 代理模型 → 采集函数 → 新真实评估 → 更新代理 → 预算停止`。

证据：每轮真实评估、约束可行性、best-observed 与 predicted-best 分离、与随机/网格/局部搜索同预算比较。没有真实反馈闭环时只能称离线代理搜索。

## 3. 精确子问题与启发式外层

适用：完整问题困难，但给定外层离散选择后，内层 LP/MIP/CP/凸问题可精确或有界求解。

链路：`外层候选 → 精确内层/约束传播 → 可行修复 → 目标重算 → 候选更新`。

证据：内外变量接口、不可行候选处理、下界/上界或小规模最优对照、同预算启发式基线。启发式输出不得声称全局最优。

## 4. Pareto 解集与偏好决策分离

适用：存在真正冲突的多个目标，需要同时展示效率边界与决策偏好。

链路：`多目标可行集 → Pareto 前沿 → 多样性/收敛检查 → AHP/EWM/VIKOR 等偏好筛选`。

证据：不先用权重把多目标静默压成单目标；权重只用于前沿内选择；报告前沿、极端方案、权重扰动和排名稳定性。EWM 不是“客观真理”，AHP 必须一致性检验。

## 5. 表示/分解与下游模型

适用：有可说明的噪声频带、空间关联、共线性或高维结构。

链路：`仅训练集拟合变换(PCA/小波/特征提取) → 下游预测/分类 → 端到端外部验证`。

证据：无变换基线、变换维数/频带消融、变换只在训练折拟合、逆变换或物理解释。仅因为“降维后图更好看”不构成创新。

## 6. 机理模型与数据残差校正

适用：已有守恒、几何或动力学主干，但参数误差或未建模扰动造成系统性偏差。

链路：`机理主干 → 参数辨识 → 训练期残差模型 → 约束内修正 → 守恒/边界复核`。

证据：纯机理基线、纯数据基线、混合模型、参数可辨识性、域外/极端条件。数据修正不能破坏物理边界。

## 7. 预测--优化与不确定性传播

适用：预测结果直接驱动库存、调度、定价、种植或资源配置。

链路：`滚动预测 → 误差/场景生成 → 随机/鲁棒/机会约束优化 → 决策回测`。

证据：预测指标与决策指标同时报告；与“真实未来已知”的上界、简单安全策略和点预测策略比较；检查分布漂移和相关误差。

## 8. 在线重规划与不可撤销决策

适用：切割、交通、生产或应急问题中，事件到达后才能获得新信息。

链路：`离线计划 → 事件触发 → 状态更新 → 滚动窗口求解 → 安全回退`。

证据：信息到达时刻、冻结决定、求解时限、每次修订的可行性和相对离线/贪心基线的收益。

## 组合模型的准入问题

任何“X + Y”在进入推荐路线前必须回答：

1. X 的已观察不足是什么？
2. Y 接收什么输入、产生什么输出，接口是否无泄漏？
3. Y 为何能修复该不足，而不是重复 X？
4. X、Y、X+Y 三组是否在同一数据、预算和指标下比较？
5. 若组合失败，保留哪个简单模型作为回退？

任一问题无法回答时，组合只能记为待验证想法，不计为创新。
