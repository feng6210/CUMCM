## 六种高频复合结构

1. **机理 → 标定 → 控制/优化**：先证明方程和参数可信，再优化控制量；不能直接用黑箱代替守恒或几何。
2. **数据 → 预测 → 决策**：预测误差必须进入后续优化的情景、区间或鲁棒项；点预测不是确定真值。
3. **统计 → 决策**：抽样误差、置信界或后验分布要改变决策规则，而不是只作附加图。
4. **几何 → 离散搜索 → 连续核验**：离散候选用于降维，最终在连续几何和物理约束上复算。
5. **离线方案 → 在线事件 → 滚动修订**：明确哪些决定不可撤销、何时获得新信息、如何生成可行回退。
6. **确定性基线 → 不确定情景 → 预案集**：先验证无随机性的容量/约束，再引入分布、相关性和追索动作。

## 拆题时必须生成的接口

对每一问记录：上游输入版本、当前决策/状态、待估参数、输出表格、精度、下游消费者、独立验证和失败回退。若后一问把前一问结果当输入，必须决定传递点值、区间、场景集还是完整分布。
