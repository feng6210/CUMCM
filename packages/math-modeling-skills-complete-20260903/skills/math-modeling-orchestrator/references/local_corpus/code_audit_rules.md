# 数模代码静态与运行审查规则

## 通用四层门

1. **语法层**：文件可解析、依赖可声明、入口明确。只通过这一层不得声称算法可用。
2. **语义层**：变量、方向、单位、状态转移、目标和约束与公式一致。
3. **数值层**：求解状态、残差、收敛、边界、守恒、随机误差和异常路径通过。
4. **结论层**：基线/对照、真实数据、协议一致性和结果到声明映射通过。

## 强制反例检查

- 示例或随机生成数据必须标记 `DEMO_ONLY`；不得进入真实结论或论文数字。
- 时间序列按时间切分；预处理、PCA、插补和特征选择只在训练折拟合。
- 预测残差修正使用训练期滚动/折外残差，不能用测试真实值训练。
- 训练、调参和最终评估分离；同一对象、批次或相邻帧不能跨集合泄漏。
- 多随机性算法保留所有预定种子/初值运行；不只报告最佳一次。
- 每个求解器检查 `success/status/termination`、原始约束和目标重算；状态成功不等于全局最优。
- 整数/排列解在舍入或修复后重新验证，不能只检查连续松弛解。
- 遗传/粒子群/退火报告预算、初始化、停止条件、可行率和多次分布。
- 结果文件与图表不从控制台文本手抄；统一写机器可读输出。

## 方法专属检查

### NSGA-II / MOPSO

- 未分配 rank 使用独立哨兵，不能与第一前沿 rank 混用。
- 支配关系要求“所有目标不差且至少一个严格更好”。
- 拥挤距离在每个前沿内部计算，并处理零目标范围。
- 父子代合并后按前沿逐层截断；记录前沿规模、可行率、超体积/间距或等价诊断。

### TOPSIS / 组合评价

- 指标方向先显式正向化；常数列和零范数必须处理。
- `argsort` 的返回索引、名次和样本编号分别保存，避免排序输出错位。
- 权重来源、归一化、理想解、贴近度和排名均写入机器可读结果。
- DEA 得分、原始投入产出和 TOPSIS 指标可能重复计入同一信息，必须审查双重计权。

### GM(1,1) / 时间序列

- 检查级比或适用性，参数估计优先稳定线性代数而非显式矩阵求逆。
- 后验差比与小误差概率不能代替时间外推回测。
- 报告滚动预测、简单朴素基线、残差和外推范围。

### ODE / 机理模型

- 检查积分器成功、状态非负、守恒/平衡、事件和边界。
- 做步长/容差收敛、参数可辨识性和初值扰动；平滑曲线不是验证。

### 排队、仿真与概率

- 明确独立性、到达/服务分布、预热、稳态和重复次数。
- 联合事件不能把有重叠的单事件概率简单相加。
- 报告 Monte Carlo 标准误与置信区间，并保留极端情景。

## 代码接收结论

使用 `SOURCE_ONLY`、`DEMO_ONLY`、`STATIC_OK_RUNTIME_UNVERIFIED`、`RUNTIME_VERIFIED`、`EVIDENCE_ELIGIBLE` 五级状态。只有最后一级才允许作为论文结论的直接计算来源；静态检查不得输出模型语义 PASS。
