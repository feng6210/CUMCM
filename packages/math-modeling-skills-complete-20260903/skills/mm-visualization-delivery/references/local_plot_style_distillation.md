## 蒸馏结论

可吸收的不是“某一张图的皮肤”，而是以下稳定语法：

1. **比较层级**：先用位置和长度比较，再用颜色强调。基线或其他方案降饱和，主方案仅用一个强调色。
2. **数据与汇总同屏**：样本量允许时，箱线/柱形旁保留原始点；误差棒必须说明误差定义、重复单位和样本量。
3. **连续结果连续编码**：二维场、相关矩阵和响应面使用连续色标并给出 colorbar；同一组面板固定色域，禁止每个面板自动缩放后伪装可比。
4. **小倍图而非拥挤叠加**：不同量纲、尺度或任务拆成共享语法的 2--4 个面板，面板标记用 `a, b, c...`，解释进入图题。
5. **线与点双重编码**：多序列同时使用低饱和颜色、点型和必要线型；标记宜为空心或白心，减少重叠色块。
6. **区间优于装饰填充**：半透明带只能表达置信区间、预测区间、可行域或真实累计量；不得仅为“高级感”填色。
7. **横向布局解决长标签**：方案名或指标名较长时使用水平点图、水平条形或哑铃图，而不是旋转成难读的竖排文字。
8. **精确值与趋势分工**：图上只标关键值或差值，完整精度写入结果表；避免每根柱都堆叠五位小数。

## 默认视觉配置

### `cumcm-clean`（默认数据图）

- 白底、二维、无阴影、无渐变、无图内标题；顶部和右侧边框隐藏。
- 全宽图约 155--160 mm，单栏图约 80--90 mm；必须在论文最终尺寸检查。
- 最终文字通常 8--10 pt，最低不得小于 7 pt；坐标轴 0.8 pt 左右，数据线 1.0--1.4 pt，点 4--6 pt。
- 默认色板：深蓝 `#2F5D7C`、橙 `#D9822B`、绿 `#4C956C`、紫 `#8A6FB0`、砖红 `#C65D57`、灰 `#5F6B73`。
- 网格只沿读数方向出现，使用浅灰细线；零线、阈值或约束边界使用独立线型并在图题解释来源。
- 图例优先置于图框上方并压成 1--3 列；只有不会遮挡数据时才放图内。两条或三条线能够直接标注时，优先取消图例。

### `cumcm-highlight`（方案择优/权衡）

- 所有备选方案使用灰蓝或浅灰；被批准且证据支持的主方案使用单一橙色强调。
- 两版本、两状态或前后变化优先哑铃图/坡度图；类别多、标签长时横向排列。
- “最优”仍由结果表和验证决定，颜色不能制造最优性。

### `cumcm-data-dense`（热图/分面/大样本）

- 连续变量采用感知均匀色图（默认 `cividis`）；有明确中性中心的偏差/相关量才用发散色图。
- 大样本散点使用透明度、较小点和必要抽稀；抽稀规则必须固定且记录，不能只保留好看的点。
- 热图单元注释只在最终尺寸仍可读且单元数量不大时使用；否则保留 colorbar 和精确数值表。
- 多面板共享轴限、色域、字体和线宽；不同量纲不得共用一个视觉刻度。

### `cumcm-vivid`（鲜明/炫酷但仍可审计）

- 允许更鲜明的青绿、珊瑚、金黄、蓝紫配色，以及适度透明填充、纹理、局部放大和有层次的多面板。
- 渐变、阴影、发光和三维不是自动禁用项；只有在增强变量层级、空间结构或视觉焦点时使用，并保证灰度打印与小尺寸阅读仍清楚。
- 装饰效果标记为非语义编码，图例不能暗示其代表新变量；关键比较仍由位置、长度、形状、线型和文字承担。
- 若“炫酷”效果导致遮挡、数值难读、跨图色域不可比或版面喧宾夺主，则退回 `cumcm-clean`，不是因风格名称而失败。

### `cumcm-mechanism`（Visio/FigureSpec）

- 使用一条主阅读路径、浅色语义分组和短标签；节点只写对象/动作/状态，解释移入图题和正文。
- 默认节点浅灰蓝、主边深灰蓝、反馈边虚线；不使用阴影、渐变、立体块或彩色大标题。
- 相同实体跨图保持颜色、形状和符号一致；方程符号必须逐字一致。
- 一张图只承担一个机制任务；审计链、数据链和算法链不全部塞进同一张图。

## 图型升级规则

| 原始倾向 | CUMCM 交付图 |
|---|---|
| 两组并排柱形比较前后变化 | 哑铃图/坡度图；若必须保留柱形，减少边框和标签精度 |
| 均值柱形 + 误差棒 | 原始点 + 区间/箱线；仅汇总数据存在时才保留柱形 |
| 多彩折线 | 低饱和色 + 点型/线型，直接标注或紧凑图例 |
| 大量类别竖排标签 | 水平点图/条形图或分面 |
| 相关/响应矩阵 | 固定色域热图 + colorbar + 必要数值注释 |
| 局部细节看不清 | 有边界标记的局部放大窗；正文说明放大范围，不能改变统计口径 |
| 多量纲双 Y 轴 | 上下对齐子图；确有共同机制才允许受控双轴 |
| 三维曲面展示“高级感” | 等高线/投影/切片；第三维真实且二维不足时才保留 3D |

## 只因误导或不适用而拒绝

- 无法区分类别、灰度后失效或与变量语义冲突的颜色组合；每次运行随机换色。
- 挡住数据、压缩绘图区或让证据层级失焦的巨型标题、图例、发光、阴影、渐变和三维效果。
- 仅凭样例代码生成的随机数据、随机误差、随机透明度和随机颜色。
- 没有统计检验、比较族与多重比较策略的星号或 `p` 值括号。
- 为显得差异更大而截断轴、改变长宽比、删点或给可比面板使用不同色域。
- 多条量纲不同序列塞入同一坐标系；双 Y 轴必须记录二维替代检查。
- 通过图片目测、截图数字或像素位置重建论文结果。
- 软件 GUI、代码窗口或教程截图作为正式证据图。

## 实现入口

- MATLAB：`scripts/cumcm_plot_style.m` 与 `scripts/matlab_plot_from_spec.m` clean-room 重建鲜明配色、点线双编码、透明填充、箱线、热图和哑铃图语法，输出 `.fig + PDF + PNG + 哈希报告`。
- Matplotlib：`scripts/cumcm_plot_style.py` 提供字体回退、版面尺寸、色板、轴样式和紧凑图例；`scripts/matplotlib_plot_from_spec.py` 默认调用。
- Origin：`scripts/origin_plot_from_csv.ps1` 的 `cumcm-clean`/`cumcm-highlight` 样式只改变表现，不改变轴范围或数据。
- Visio：`scripts/visio_diagram_from_spec.ps1` 默认使用 `cumcm-mechanism` 的浅色、细线和短标签语法。
- 任何后端成功仅表示渲染和重开成功；只有来源、变换、数值、声明与视觉审查全部通过才是 `EVIDENCE_ELIGIBLE`。
