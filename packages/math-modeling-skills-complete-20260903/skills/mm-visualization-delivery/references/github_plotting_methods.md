# GitHub 画图方法的数模本地化

本参考把多个开源画图 Skill 中可复用的方法重写为 CUMCM 中文论文规则。来源、固定提交和许可证见 `github_derivation_notice.md`。这里的规则已经本地化，运行时不访问 GitHub，不要求 API、云端模型或外部仓库。

## 1. 先判断是否应该画图

每个候选图先回答四个问题：

1. 该图要回答哪个分问或支持哪个 `claim_id`？
2. 读者需要比较、看趋势、看分布、看关系，还是理解机制与流程？
3. 源数据和变换能否机器重算？
4. 表格或一句话是否比图更清楚？

没有明确用途、数据点过少、所有值相同或只为装饰的候选图可以不画。先满足每个分问至少 4 个不同物理图件的最低覆盖线，再按证据需求增加；4 图是最低线而不是固定上限。若某个可选槽位确无信息增益，必须说明具体省略理由，并用其余互不复用的证据图补足最低线。

图还必须先归入 `orientation`、`mechanism`、`evidence` 或 `validation`。导航图只解释论文路径；机制图必须连接符号与方程；证据图展示趋势、分布或权衡；验证图检验残差、约束、收敛或扰动。精确答案优先放结果表，不从图上目测抄写。论文级导航可用 `question_id: paper`；不承担结果声明的导航/机制图可用 `claim_id: not_applicable` 和 `exact_values_location: not_applicable`；证据/验证图必须绑定真实 `claim_id` 和精确值位置。

## 2. 数据图选型

| 读者任务或数据结构 | 首选图型 | 重要约束 |
|---|---|---|
| 时间、迭代步、空间位置上的连续变化 | 折线图 | 多序列过多时分面；必要时显示区间带 |
| 少量类别比较一个指标 | 条形图 | 零基线通常必要；类别较多改横向条形 |
| 类别比较多个指标 | 分组条形或分面图 | 不用雷达图隐藏量纲差异；指标量纲不同则分面 |
| 单变量或分组分布 | 箱线图、小提琴图或直方图 | 标明样本量和箱线/误差定义 |
| 两个连续变量关系 | 散点图 | 拟合线与相关系数属于新统计量，必须回到验证 |
| 网格、相关矩阵、混淆矩阵 | 热图 | 使用感知均匀色图；给出色标和数值含义 |
| 构成且总和有明确意义 | 堆叠条形图 | 不默认使用饼图；百分比总和需核对 |
| 排名或单指标多方案 | 横向点图或条形图 | 排名变化应保留原值和不确定性 |
| 路径、轨迹或空间分布 | 轨迹图、地图或等值图 | 坐标系、比例尺、方向和单位必须明确 |
| 收敛与灵敏度 | 收敛曲线、龙卷风图或参数—响应曲线 | 阈值和扰动范围必须来自实验计划 |

默认拒绝三维柱状图、透视饼图、彩虹色图和没有披露的双纵轴。截断坐标轴只有在不误导且图中明确标记时才可使用。

## 3. 结构、机制和流程图选型

先列出实体、关系、分组、主流向、反馈和边界，再选择图型：

| 语义 | 图型 | 主后端 |
|---|---|---|
| 分步算法、赛题求解链、交接流程 | 流程图 | Visio；回退 FigureSpec/SVG |
| 组件、层级和模型子模块 | 结构/架构图 | Visio；回退 FigureSpec/SVG |
| 状态及转移条件 | 状态图 | Visio；回退 FigureSpec/SVG |
| 主体间有时间顺序的交互 | 时序图 | Visio；简单场景可回退 Mermaid |
| 节点、边、流量或传播关系 | 网络拓扑图 | Visio 或专用网络绘图；回退 SVG |
| 决策分支和回退路线 | 决策流程图 | Visio；回退 FigureSpec/SVG |

布局规则：

- 主流向固定为左到右或上到下，反馈边与主路径视觉区分。
- 相同语义角色使用相同形状、字号和颜色；颜色不是唯一编码。
- 连接线应在节点边界结束，避免穿过节点、文字和三个以上层级。
- 先绘制分组与连线，再绘制节点与文字，保证遮挡关系稳定。
- 中文标签优先短语；长解释移到图题。不得通过缩小字体解决过密布局。
- 图中每个机制、约束和反馈都必须能在模型、算法或文字中找到依据。
- 同一实体跨多个机制图保持固定颜色、形状、线型和方向；图中符号与正文公式完全一致。
- 流程图必须包含真实输入、关键分支或迭代、停止条件和输出；章节标题的方框排列不算算法图。

## 4. CUMCM 中文风格

- 默认白底、二维、低装饰、适合打印；不套用 ML 会议深色背景或“突出我方方法”样式。
- 使用中文可用字体并在目标机器上实际渲染。不要依赖网络字体。
- 图内默认不放标题，LaTeX `\caption{}` 承担中文标题和解释，图号由 LaTeX 生成。
- 坐标轴必须是可读中文名称并带单位；禁止仅显示程序变量名。
- 连续量优先使用感知均匀色图；类别色优先采用色盲安全配色，并辅以点型、线型或纹理。
- 论文中优先嵌入矢量 PDF；照片、遥感影像等天然栅格内容可使用高分辨率 PNG。
- 同一篇论文统一字体、字号、线宽、色板、尺寸和小数位规则。
- 正文多面板常规优先 2--4 个且共享可比尺度；超过 4 个说明不可拆分理由，超过 6 个优先移至附录。
- 美观以层级、对齐、留白、比例和语义一致为准，不以彩虹色、阴影、透视或软件默认主题为准。
- 默认使用 [本地优秀图形语法蒸馏](local_plot_style_distillation.md) 的 `cumcm-clean`；方案择优使用 `cumcm-highlight`，热图/分面使用 `cumcm-data-dense`，机制图使用 `cumcm-mechanism`。风格名称不能替代最终尺寸视觉检查。
- 两状态比较优先哑铃图/坡度图，长类别优先横向点图/条形图；均值柱形只有在原始分布不可获得且误差定义完整时才优先。

## 5. 永久正确性规则

这些规则不因审美选择而放宽：

- 被排除、无效、超时或不可行的运行不能静默进入汇总；如绘制，必须视觉区分并在图题说明。
- 图题和图内声明必须对每一个绘制数据行成立。
- 不同样本量、预算、随机种子协议、参数范围或评估口径不能伪装为直接可比。
- 所有均值、区间、拟合、排序和相对改善必须能从源数据和变换脚本重算。
- 标明误差条或区间的含义、样本量和重复单位；不能把标准差、标准误和置信区间混写。
- 不用最好随机种子、最好初值或最好参数冒充均值或稳健结果。
- 相对改善的分母接近零时，改报绝对差异或给出明确限制。
- 图形渲染成功只证明文件可读，不证明模型、统计或论文声明成立。

## 6. 产物契约

每张图至少保留：

```text
FIGURE_INTENT 条目
源数据或数据定位
变换/生成脚本或原生后端操作记录
可编辑源文件
XeLaTeX 用 PDF 或必要时 PNG
中文图题和 LaTeX label
重开与最终尺寸检查结果
源文件和输出文件 SHA-256（正式交付时）
```

图表修改必须改源数据、规范或生成脚本后重跑，不直接修补导出的 PDF、PNG 或 SVG。

`FIGURE_INTENT` 中的 `visual_grammar` 至少记录字体、最终字号、色板和线宽；同一 `visual_grammar_group` 的条目必须一致。`placement` 使用 `body` 或 `appendix`：正文超过 6 个面板默认失败，附录只有在说明不可拆分理由后才允许高密度面板。
