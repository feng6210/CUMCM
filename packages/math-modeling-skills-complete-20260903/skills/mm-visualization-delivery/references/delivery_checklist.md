# 结果交付检查清单

## A. 结果与模板

- [ ] 每一问都有明确交付物，文件名与题目一致。
- [ ] 表格字段顺序、行数、单位、小数位和缺失值规则已核对。
- [ ] 原始题目模板未被破坏，Excel 公式与工作表名称保留。
- [ ] 图表由机器可读结果生成，轴、图例、单位、样本量与不确定性完整。
- [ ] 正文、摘要、图、表、附件中的关键数字自动或逐项交叉核对。
- [ ] 可行解、最优解、局部解、估计值和预测值标签明确。
- [ ] 无解、不可达、未定义和未验证没有被填成 0。

## B. Figure planning：先检查“该不该画”

- [ ] `coverage_plan` 已逐问检查 orientation、mechanism、main_result、comparison、validation、robustness 等读者任务，并为每项选择 `figure / table / text / appendix / not_applicable`。
- [ ] **没有使用“每问至少 N 张图”或“每个核心结论必须配图”的硬数量规则。**
- [ ] 每个保留图都有明确 `reader_takeaway`；如果删除该图不会损失任何理解或判断，已经删除或移入附录。
- [ ] 复杂几何、物理、受力、状态或 case 判据优先检查是否需要二维机制图；不能只用公式 + 收敛/误差图替代模型解释。
- [ ] 当问题从单主体升级为多主体、多资源、多阶段时，如结构理解发生变化，已考虑协同关系、时间区间或空间部署图。
- [ ] 算法流程图只在算法本身构成理解障碍时保留，且包含真实输入、分支/迭代、停止条件和输出。
- [ ] 精确值优先由三线表承担；图和表完全重复且图没有结构/趋势/空间/权衡/误差任务时删去其一。
- [ ] `competition_compact` 正文优先保留模型解释、核心策略/结果和真正关键验证；完整多种子、微小数值误差、后端审计、版本谱系和参数全扫描已优先移入附录/支撑材料。
- [ ] `research_audit` 若保留更多验证图，正文仍未因审计图遮蔽模型主线。

## C. Figure rendering：再检查“画得对不对”

- [ ] 每个 `representation: figure` 条目都有完整 `FIGURE_INTENT`：分问、用途、来源、变量、单位、变换、后端、可编辑文件、LaTeX 文件和中文图题。
- [ ] 每张图标明 `narrative_role`、`reader_takeaway`、`exact_values_location`、`visual_grammar_group`、`visual_grammar` 和 `placement`。
- [ ] `visual_grammar` 已明确 `style_profile`、最终宽度、图例策略、精度策略和 `decorative_effects`；视觉效果不改变数据含义。
- [ ] 导航图不冒充证据；机制图的符号与公式一致；证据/验证图与精确结果表采用同一口径。
- [ ] 图型与读者任务匹配；没有为了装饰增加饼图、3D、双纵轴、发光或无意义渐变。
- [ ] 能用二维投影、截面、等高线或时间轴解释时没有强行 3D；保留 3D 时有真实第三维必要性和投影/切片/关键点/结果表。
- [ ] 多面板在最终论文宽度仍可读；常规优先 2--4 个，超过 4 个有不可拆分理由，超过 6 个优先附录。
- [ ] 同一实体跨图使用一致颜色、形状、线型和方向；颜色不是唯一编码。
- [ ] 两状态比较已评估哑铃/坡度图替代并排柱形；长标签优先横向图。
- [ ] 误差棒注明不确定性类型、区间/置信水平及样本量来源，没有把 SD、SE、CI、预测区间或数值误差混写。
- [ ] 星号/`p` 值具有统计检验、比较族和多重比较策略；类别渐变绑定真实连续变量。
- [ ] 图内不放论文式标题；中文图题、解释、样本量和区间含义写入 LaTeX caption。

## D. 来源、后端与可复现

- [ ] 每张图的来源路径和 SHA-256 可定位；新拟合、平滑、区间、排名或统计量已回写机器可读结果并通过验证。
- [ ] Origin/Visio 原生文件已由原生应用重新载入，导出 PDF 已在论文最终尺寸重开检查。
- [ ] MATLAB/Matplotlib 绑定 renderer spec；后端报告与实际字体、色板、宽度、输出和来源一致。
- [ ] 原生后端失败时使用真实回退文件，没有伪造 `.opju`、`.vsdx` 或 PDF。
- [ ] 图中没有裁切、遮挡、乱码、网络字体、过小文字、颜色唯一编码和未解释缩写。
- [ ] 输出重新打开后检查类型、关键值和可读性；矢量内容优先 PDF。
- [ ] 运行命令、依赖版本、随机种子和输出路径可复现。
- [ ] GitHub 只出现在许可证/来源说明中，不是数学结果门控或运行依赖。

## E. 竞赛叙事检查

- [ ] 正文的图先帮助评委理解“题目 → 数学结构 → 方法 → 结果”，而不是先展示工程验证链。
- [ ] 若正文出现 gate 名、hash、版本 FAIL 谱系、后端 runtime report，已确认这些信息确实影响科学判断；否则移入支撑材料。
- [ ] 图的密度没有导致模型方程、变量、关键策略和结果解释被压缩到难以阅读。
- [ ] `figure planning` 和 `figure rendering` 已分离；渲染阶段没有自行增加图量。

近年赛题常要求精确写入 Excel 或输出大规模坐标/轨迹。交付正确性是建模质量的一部分：数学上正确但字段错位、单位错误或手工抄错的结果仍不可用。
