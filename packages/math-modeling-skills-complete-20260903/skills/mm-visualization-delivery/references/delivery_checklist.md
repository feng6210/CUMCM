# 结果交付检查清单

- [ ] 每一问都有明确交付物，文件名与题目一致。
- [ ] 表格字段顺序、行数、单位、小数位和缺失值规则已核对。
- [ ] 原始题目模板未被破坏，Excel 公式与工作表名称保留。
- [ ] 图表由机器可读结果生成，轴、图例、单位、样本量与不确定性完整。
- [ ] `coverage_plan` 已逐问覆盖数据诊断、模型机制、主结果、对比、验证和稳健性；每问至少 4 个互不重复图号和实际图件，不共享 PDF/原生文件/后端报告哈希，主结果与验证使用内容独立的不同正文图，其他槽有图或具体不适用理由。
- [ ] `expected_question_ids_source` 已绑定题目拆解文件、字段和 SHA-256，未出现分问同时从覆盖计划与图表中消失。
- [ ] 每个核心结论至少绑定一张证据图或验证图；图量不足时补的是证据链缺口，而不是重复图或装饰图。
- [ ] 每张图都有完整 `FIGURE_INTENT`：分问、用途、声明、源数据、变量、单位、变换、后端、原生文件、LaTeX 文件和中文图题。
- [ ] 每张图标明 `narrative_role`、`reader_takeaway`、`exact_values_location`、`visual_grammar_group`、`visual_grammar` 和 `placement`；同组字体、色板、线宽与实体样式一致，没有不可替代读者任务的图已删除。
- [ ] `visual_grammar` 已明确 `style_profile`、最终宽度、图例策略、精度策略和 `decorative_effects`；鲜明效果完成遮挡、灰度、最终尺寸和去除效果对照，不使用不可审计的后端默认主题。
- [ ] 导航图不冒充证据，机制图的符号与公式一致，证据/验证图与精确结果表采用同一口径。
- [ ] 图型与读者任务匹配；没有为了装饰增加饼图、三维效果、双纵轴或无意义配色。
- [ ] 排除数据未进入汇总；不同样本、预算和评估协议没有被画成直接可比。
- [ ] Origin/Visio 原生文件已由原生应用重新载入，导出 PDF 已在论文最终尺寸重开检查。
- [ ] 每张图的 `backend_report` 已绑定哈希；MATLAB/Matplotlib 同时绑定 `renderer_spec`，报告的 `render_contract` 与声明图型、变量和变换一致；报告内全部输入、原生文件、PDF、实际字体/色板/透明效果、最终宽度、有效字号、重开及匿名状态与实物一致。
- [ ] 图中没有裁切、遮挡、乱码、网络字体、过小文字、颜色唯一编码和未解释缩写。
- [ ] 误差棒注明不确定性类型、区间/置信水平及样本量来源，没有把 SD、SE、CI、预测区间或数值误差混写。
- [ ] 多面板图在最终论文宽度仍可读；超过 4 个面板有不可拆分理由，超过 6 个面板已优先移至附录。
- [ ] 三维图附带投影、切片、关键点标注或精确结果表；没有软件界面、代码窗口或装饰性流程图截图。
- [ ] 图内不放论文式标题；中文图题、解释、样本量和区间含义写入 LaTeX caption。
- [ ] 类别色没有无语义渐变；星号/`p` 值具有统计检验、比较族和多重比较策略；两状态比较已评估哑铃/坡度图替代并排柱形。
- [ ] 新拟合、平滑、区间、排名或统计量已回写机器可读结果并通过模型专属验证。
- [ ] 原生后端失败时使用真实回退文件，没有伪造 `.opju`、`.vsdx` 或 PDF。
- [ ] 正文、摘要、图、表、附件中的关键数字自动或逐项交叉核对。
- [ ] 可行解、最优解、局部解、估计值和预测值标签明确。
- [ ] 无解、不可达、未定义和未验证没有被填成 0。
- [ ] 运行命令、依赖版本、随机种子和输出路径可复现。
- [ ] GitHub 只出现在许可证/来源说明中，不是运行依赖、门控或交付状态。

近年赛题常要求精确写入 Excel 或输出大规模坐标/轨迹。交付正确性是建模质量的一部分：一个数学上正确但字段错位、单位错误或手工抄错的结果仍然不可用。
