# 本地图表代码蒸馏与交付规则

## 审计事实

- 来源快照含 1 份 8 页扫描教程、5 份 Python 与 5 份 Matlab 文件，共覆盖约 50 类图表。
- Python 脚本均使用随机示例数据，5/5 在 Matplotlib `Agg` 后端可执行；全部缺少文件导出与主动关闭图窗，因此状态只能是 `DEMO_ONLY`。
- Matlab 文件为 UTF-8 文本，在当前 Windows/MATLAB 默认编码下 5/5 解析失败；转成临时 GBK 副本后代码主体可运行，但有一处图例对象数量警告。不得修改原始资料来掩盖此兼容性问题。
- 扫描教程给出的“适用赛题类型”只是启发式索引，不能替代数据结构、声明目标和最终版面判断。
- 追加审阅的 `D:\数模文件\画图` 共含 145 个文件，其中 68 个 JPG/PNG 视觉样本、32 个 Matlab 和 5 个 Python 文件。样本质量不一致，且未发现明确许可证；因此只蒸馏通用图形语法，不复制源码、图片或演示数据。详细规则见 [local_plot_style_distillation.md](local_plot_style_distillation.md)。
- 样本的鲜明配色、组合构图、渐变和三维投影是可采用的设计资源，不因“炫酷”而拒绝。拒绝的是虚构数据、无检验星号、遮挡和误导尺度；按样式卡继承配色与布局，按当前结果重新作图。

## 图型路由

| 分析目的 | 首选 | 条件与必要检查 |
|---|---|---|
| 两连续变量关系 | 散点 + 有证据的拟合/区间 | 点透明度、样本量、异常点规则、拟合协议 |
| 时间或迭代趋势 | 折线/阶梯/收敛曲线 | 时间顺序、缺失间隔、区间或多次运行分布 |
| 类别数值比较 | 点图、水平条形、分组条形 | 零基线、排序含义、误差或区间 |
| 组成及其变化 | 堆叠条形/百分比堆叠/面积 | 总量与占比不能混写，类别不宜过多 |
| 单变量分布 | 直方图 + KDE、箱线、小提琴 | 样本量、带宽、离群规则、组间同尺度 |
| 多变量关联 | 散点矩阵、相关热图 | 相关方法、缺失处理、多重比较或非线性边界 |
| 不确定性/参数估计 | 误差棒、区间带、森林式点区间 | 区间定义、重复次数、分母和置信水平 |
| 二维标量场 | 热图/等高线 | 颜色范围、插值方法、网格分辨率、原始点覆盖 |
| 向量或空间场 | 矢量场/轨迹/地图 | 坐标系、尺度、方向单位、抽稀规则 |
| 多目标结果 | Pareto 散点/平行坐标 | 非支配定义、可行解、目标方向、偏好后置 |

## 国奖论文中的图表叙事角色

先为图指定角色，再选图型：

| 角色 | 读者任务 | 常见载体 | 不承担什么 |
|---|---|---|---|
| `orientation` | 看懂分问依赖、总流程或必要场景 | 关系图、总流程图、简化场景图 | 不证明数值结论 |
| `mechanism` | 从实体/符号/几何/状态走到方程或算法 | 坐标图、受力图、几何图、状态/算法流程图 | 不凭美观增加模型机制 |
| `evidence` | 看趋势、分布、比较、轨迹或权衡 | 折线、散点、条形、热图、轨迹、Pareto 图 | 不代替精确结果表 |
| `validation` | 判断拟合、约束、稳定性和误差 | 残差、敏感性、收敛、扰动、基线对照 | 不把一次运行写成稳健性 |

同一组机制图必须共享视觉语法：相同实体使用相同颜色、线型、形状和方向，标签与公式符号一致。证据图优先组成“原始/处理后、基线/主模型、名义/扰动、拟合/残差、目标/约束余量”等可比较对。

## 受限图型

- 饼图、环形图：仅用于少量互斥且总和明确为 100% 的类别；优先比较时改用条形图。
- 雷达图：仅用于量纲已统一、方向已正向化且指标数较少的多方案概览；论文结论仍须来自数值表与敏感性分析。
- 双 Y 轴：仅在同一横轴上展示两个尺度不同但机制相关的变量，并明确颜色—坐标轴绑定；若容易制造虚假同步趋势则拆成对齐子图。
- 3D 图：第三维真实承载空间或响应结构、视角不遮挡即可使用，并与二维投影互补；不得把 3D 柱状图当“更高级”的类别比较。
- 大面积填充、瀑布、马赛克、Andrews 曲线：先说明编码语义和读者任务；不能只为装饰使用。
- 多面板：正文常规优先 2--4 个共享尺度的面板；超过 4 个必须记录不可拆分理由，超过 6 个优先移到附录。不得靠缩小字体塞图。
- 三维曲面：除记录必要性和二维替代检查外，必须提供投影、切片、关键点标注或精确结果表之一。

## 从演示到可交付的强制升级

1. 删除随机示例数据，绑定 `FIGURE_INTENT.yaml` 中的真实机器可读来源与 `claim_id`。
2. 固定数据变换、筛选、排序、误差定义、颜色和版面尺寸；变换必须可重算。
3. 图内默认不放论文式标题；中文图题进入 LaTeX `\caption{}`，轴名写变量和单位。
4. 输出 PDF 和 SVG；真正的栅格内容另输出 300 dpi 以上 PNG。Python 必须 `savefig(..., bbox_inches="tight")` 并 `close(fig)`。
5. Origin/Visio 原生文件必须重开验证；Matplotlib 输出必须重开、检查裁切和中文字体。
6. 写输出 SHA-256、数据 SHA-256、脚本/配置、环境版本和警告。任何警告未解释时不得标为最终交付。
7. 最终尺寸检查可读性、线宽、图例、色盲友好、黑白打印和 LaTeX 包含效果。
8. 精确答案由结果表承担；若图与表表达完全相同且图没有机制、趋势、权衡或稳健性任务，删除其一。
9. 机制/流程图检查实体、关系、坐标、约束、停止条件和输出是否能逐项回指正文；软件界面截图、代码窗口截图和章节目录式流程图不得作为最终证据图。

执行成功只允许写 `RUNTIME_VERIFIED`；只有真实来源、重算、声明审查、导出重开和视觉检查全部通过才允许 `EVIDENCE_ELIGIBLE`。
