# 结果验证协议

验证分五层，不能互相替代：

1. **结构**：输入字段、单位、维度、缺失和范围正确。
2. **数值**：残差、收敛、步长、容差、约束和目标可重算。
3. **统计**：划分、区间、校准、抽样和多重比较合理。
4. **稳健**：关键参数、权重、种子、场景或模型变化后结论不轻易翻转。
5. **外部**：与题目给定值、已知极限、独立数据或现实规律一致。

每个声明填写：`claim_id / source_result / validation / threshold / status / limitation`。没有预设阈值时只能给探索性结论。

国奖案例启示：2022 A 用数值阶和误差范围描述“最优区间”而不是假装最优点绝对精确；2025 B 同时使用跨角度拟合、解析峰值、频域方法、敏感性和蒙特卡洛互证。新版要求至少一项同源核验与一项异源核验。
