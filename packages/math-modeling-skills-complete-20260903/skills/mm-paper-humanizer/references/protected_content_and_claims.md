# 数学建模论文自然化：受保护内容与声明强度

## 1. 原则

自然化的第一目标不是改得“像人”，而是在不改变数学含义和证据强度的前提下提高可读性。任何语言改写都服从技术真值源：题意语义、结果工件、验证记录和结果到声明映射。

如果一句话同时包含“技术内容”和“语言外壳”，先拆分。技术内容冻结，语言外壳才允许修改。

## 2. 硬保护对象

### 2.1 LaTeX / 数学对象

默认字节级保护或语义等价保护：

- `$...$`、`\(...\)`、`\[...\]`；
- `equation`、`align`、`aligned`、`gather`、`multline` 等数学环境；
- `\label{}`、`\ref{}`、`\eqref{}`、`\cite{}`、`\autoref{}`；
- `\SI{}`、`\si{}`、`\num{}` 等数值/单位命令；
- 公式中的变量、下标、上标、正负号、等号/不等号方向；
- 算法伪代码中的条件、循环、停止规则和返回对象。

### 2.2 数值与口径

默认保护：

- 结果值；
- 百分比；
- 时间窗；
- 样本数、迭代数、种子数；
- 置信区间、显著性水平和 p 值；
- 目标函数值；
- 约束余量；
- 排名；
- 误差、残差、R²、RMSE 等评价指标；
- 输入参数及单位。

展示精度只有在用户或上游写作 Skill 明确允许时才可舍入；舍入必须与原始值一致，不能借自然化改变结果。

### 2.3 术语与实体

固定术语不做“同义词轮换”。包括：

- 模型名；
- 算法名；
- 数据集名；
- 评价指标；
- 题目中定义的对象；
- 本文已经明确定义的自创术语。

术语前后不一致属于写作缺陷，但 Humanizer 不能自行猜测哪一个才是正确名称。存在冲突时输出 `TERMINOLOGY_REVIEW_REQUIRED`。

## 3. 声明强度阶梯

优化类常见声明强度从强到弱：

1. `GLOBAL_OPTIMUM`：已证明/严格认证的连续或离散全局最优；
2. `EXACT_OPTIMUM_IN_DEFINED_DOMAIN`：在题目明确定义的有限/可枚举域内精确最优；
3. `LOCAL_OPTIMUM`：局部最优；
4. `BEST_IN_SEARCHED_DOMAIN`：当前覆盖搜索域内最好；
5. `BUDGET_LIMITED_BEST`：给定预算内最好；
6. `BEST_FEASIBLE_CANDIDATE`：当前可行候选中最好；
7. `OBSERVED_BEST`：已观测值中最好。

自然化不得把低层级升级到高层级。允许把生硬的内部术语改成人类可读表达，但必须维持同一层级，例如：

- `预算内候选` → `在当前搜索预算下得到的最优可行方案`；
- `当前网格最优` → `在所考察参数范围内取得最大值`；
- `局部最优` 不得变成 `最优解`，除非上下文已明确“局部”。

## 4. 统计与因果声明

以下变化视为 critical failure：

- “相关” → “导致”；
- “结果表明/显示” → “证明”；
- “在样本内有效” → “具有普适性”；
- “对所测扰动稳定” → “鲁棒”；
- “模型内差异” → “真实误差”；
- “数值一致” → “模型正确”；
- “未发现更优解” → “不存在更优解”。

若原文存在过度声明，Humanizer 不负责静默纠正。标记后交 `mm-paper-reviewer` 或上游技术链处理。

## 5. 边界条件的保留与迁移

### 就地必须保留

当边界直接决定读者如何解释当前数字时，边界不能移走。例如：

- 当前数值只是搜索域最优；
- 两种方法比较使用不同时间窗；
- 某区域未收敛且可能影响最优性；
- 一个结论只适用于特定参数范围；
- 一个“提升”只来自固定控制参数而不是重新优化；
- 模型内机制推断不能写成真实因果。

### 可以集中迁移

当边界不会改变当前句子的数学含义，可以移到模型评价/局限：

- 重复出现的“真实系统还需实验验证”；
- 已在假设中说明、后文又多次重复的线性化适用条件；
- 多种求解器得到一致结果的完整日志；
- hash、commit、backend、gate 等工程追溯信息。

迁移不等于删除。若它是 `RESULTS_TO_CLAIMS.md` 中声明成立的必要条件，全文必须仍能定位。

## 6. 改写前 factual inventory

每次处理长文或文件时建立内部清单：

- 核心结论；
- 每问关键结果；
- 需要就地保留的 scope marker；
- 公式/变量/单位；
- citation/ref/label；
- 技术术语；
- 对比基线；
- 不能升级的 claim。

完成后逐项核对。任何一项无法确认，停止自动定稿并标记人工复核。
