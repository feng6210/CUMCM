# 模型选型矩阵

| 问题特征 | 优先模型 |
|---|---|
| 多指标评价排序 | TOPSIS、熵权法、AHP、灰色关联、PCA |
| 时间变化预测 | 回归、时间序列、GM(1,1)、机器学习预测 |
| 资源分配 | 线性规划、整数规划、多目标优化 |
| 路径、管网与传播 | 图论、最短路、网络流、时间展开图 |
| 群体分组 | K-means、DBSCAN、层次聚类 |
| 分类识别 | 逻辑回归、决策树、随机森林、SVM |
| 随机过程 | 蒙特卡洛、排队论、离散事件仿真 |
| 连续动力机理 | ODE/DAE、状态空间、事件检测 |
| 多阶段决策 | 动态规划、滚动优化、MDP |
| 抽检与统计证据 | 二项抽样、置信区间、假设检验、功效 |
| 重复测量/事件时间 | 混合效应、GEE、生存分析、联合模型 |
| 不确定决策 | 情景随机规划、鲁棒优化、CVaR |
| 光谱与周期 | FFT、峰值检测、时频分析、物理逆问题 |
| 图像、视频和轨迹 | 标定、关键点/姿态、轨迹与事件检测 |
| 非凸黑箱优化 | 精确基线 + 多初值局部搜索或元启发式 |

## 使用提醒

- 先判定问题对象和输出，再选模型；关键词只用于提示，不能代替结构判断。
- 评价排序、预测、约束优化和统计推断是不同任务，不得混用结果含义。
- 每个主模型至少配一个简单基线和一个验证模型/方法。
- 所有结果必须带前提、最优性/统计状态和可核验边界。
