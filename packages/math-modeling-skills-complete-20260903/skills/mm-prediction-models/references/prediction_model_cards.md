# 预测模型卡

回归适合有解释变量的连续目标；时间序列基线适合有时间顺序的数据；GM(1,1) 适合小样本单调趋势但对波动序列不稳；随机森林可做非线性基线但解释性和过拟合风险需说明。

## 验证选择

| 结构 | 推荐验证 | 禁忌 |
|---|---|---|
| 普通独立样本 | 留出/交叉验证 | 全数据调参后报同数据误差 |
| 时间序列 | 滚动或最新时段留出 | 随机打乱预测未来 |
| 同对象重复记录 | GroupKFold/留对象 | 同对象跨训练测试 |
| 小样本 | 简单基线 + 重复 CV 区间 | 只报最好一次 |

至少与均值/上一时刻/线性模型等简单基线比较。报告 MAE/RMSE 等与问题代价一致的指标、测试区间和预测范围。GM(1,1) 先做级比检验与后验差检验；外推期过长时必须降级结论。
