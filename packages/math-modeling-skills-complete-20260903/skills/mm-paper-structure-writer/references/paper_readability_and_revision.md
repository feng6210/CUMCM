# 中文数模论文：读者任务与修订闭环

适用于已有证据的写作、排版修订及优秀论文对照。默认中文 CUMCM LaTeX；正式模板优先。这里是可读性方法，不是额外官方格式要求，也不要求每题复用同一种叙事结构。

## 1. 先确认修改对象

用户要求“完善 Skill”时，产物是可复用的 Skill 指令、参考、模板和必要脚本/回归；只改一篇论文不算完成。用户要求“改这篇论文”时，仅在任务目录实施，不能顺便覆盖已安装 Skill。要求推送仓库时另按明确授权完成发布；运行数模任务本身不依赖仓库或网络。

把改动分为文字/版面、图形表达、数值重算和模型变更。前两类可以消费既有证据；新数据、主模型、目标、预算或验证阈值仍需原批准流程。不要用外部论文数字替换本题结果。

## 2. 摘要与选择性强调

- 首段交代总任务与主要矛盾；分问多时按问组织短段，确有继承关系才写继承。
- 分问引导语和少量决定答案的结果可加粗。默认关键词标签及条目整行加粗，内置模板用 `\mmKeywordStyle`；正式模板或用户样式不同则服从其定义，不给整段摘要加粗。
- 原始结果保留完整精度，摘要根据有效精度适度舍入；正文表格与摘要的差别必须是舍入，不是换结果。
- 文件行数、文件名、哈希和软件日志通常进入支撑说明。未收敛覆盖缺口、适用条件、无全局最优证明等科学限制必须在论文或支撑证据中保持可见，但只有当它们会改变摘要中核心数字/“最优”等措辞的含义时才进入摘要；不要把每一项限制都压进摘要。
- 摘要一页与关键词粗体均要检查实际 PDF；命令存在不是视觉验收。

## 3. 叙事由数学对象决定

问题分析回答难点和求解依赖，不罗列软件名称。图后分析优先回答“观察到什么—模型中哪个关系解释它—对本问有何意义—证据允许解释到哪里”。没有识别或对照证据时，把因果解释限定为模型内推断。

| 问题结构 | 可尝试的论证顺序 | 不能机械套用 |
| --- | --- | --- |
| 机理/几何 | 整体对象→部件/坐标→作用与约束→核心方程→响应与解释 | 不强制完整受力图；消约束广义作用图与隔离受力图区分 |
| 预测/统计 | 数据与时序→特征/假设→模型→样本外表现→误差与范围 | 不把拟合优度或模型差当实测精度 |
| 优化/调度 | 资源与约束→可行基线→决策与目标→方案/权衡→可行性与界 | 不把求解器成功或多初值相近当连续全局证明 |
| 评价/仿真 | 指标/状态→映射或随机机制→结果→稳定性/极限检验 | 不把排名、少量试跑当因果结论或充分重复 |

共享的是方程结构不等于共享所有分问参数；传递对象及其版本写清。不为套模板制造跨问依赖。简单闭式题可不设复杂共享章节或结果图。

### 3.1 证据完整不等于正文全部暴露

`RESULTS_TO_CLAIMS.md`、`result_evidence_map.json` 和 `NARRATIVE_MAP.yaml` 可以记录完整 validation、失败覆盖、声明边界和版本来源。竞赛正文只选取对当前读者判断真正必要的部分：

- 会改变“最优/可行/显著/稳定”等结论含义的边界，就地保留；
- 最能说明模型是否算对、是否稳定的一两项验证，放模型检验或对应结果段；
- 重复的求解器日志、hash、gate、旧 FAIL 谱系、微小复算差放支撑材料。

不要把“证据链完整”误写成每个结果段都固定出现“验证—限制—不能声称”。

### 3.2 自然化阶段

技术 P0/P1 已关闭、结果和 claim scope 冻结后，可调用 `mm-paper-humanizer` 做 `light/compact` 修订。顺序是：

```text
先作者站位
→ 再段落逻辑和重复
→ 最后句式/连接词
→ 不变量核验
```

Humanizer 无权修改公式、变量、数值、引用、目标函数、约束和最优性层级。已经自然的段落允许不改，不以“改动量大”作为质量目标。

## 4. 图表的读者任务

先清点现稿再提缺图意见：已有三维、热图或机制图不得因旧印象重复添加。按读者障碍选择几何定位、作用/边界、状态或算法、参数景观、响应对照、敏感性矩阵；没有固定图数或必备图型清单。

表格承载精确值，图形展示结构与变化。重要表可适度突出候选/最优行，但说明比较域与单位。统计对照必须对齐数据、单位、时间窗口、初值、重复/聚合方法；不同窗口的差不是纯求解器误差，固定控制参数扰动不是置信区间或逐情景再优化。相对改善分母近零时不用夸大的百分比。

风格按图的用途分开：结果图可采用鲜明配色、三维与二维组合，不能把朴素当质量标准；示意、流程、结构及受力图默认白底、纯黑线条和文字，不用彩色或灰色填充，以实虚线、线宽、箭头和剖面线区分对象。示意图与彩色结果图之间以一致的实体名称、符号和正方向对应，不强求颜色一致。机制图以可编辑矢量实际绘制，不用生成式像素伪造精确几何；用户后续明确指定或正式模板另有要求时遵从其要求。

## 5. LaTeX 排版复查

- 标题、一级与次级标题明确层级；字号、行距和关键词样式是内置默认值，不冒充官方硬要求。
- 浮动体放在完整段落之后；先考虑 `[tbp]` 和章节边界的浮动限制，不用全稿 `[H]` 掩盖布局问题。检查标题孤行、段落被图表隔成半句话、图越到不相关分问。
- 符号表写表题、含义和单位；合理列宽，跨页时重复表头，不用难读小字压缩。
- 在实际论文宽度检查图中文字、箭头和图例；图注使用短标题及必要解释，不能压过正文。
- 摘要、正文、附录分别计页。总 PDF 很长未必正文超限；不得删完整源码、关键推导或必要结果来凑页数。孤尾代码页、过多留白等记录为版面问题，优先局部调整。

## 6. 修订与审查记录

保存改前版本，记录当前源、图、结果和 PDF 哈希。独立审查分为题意/数学、数字/声明、图形/版面；同一 agent 可以承担不冲突的维度，但图的生成者/编辑者不能自填独立审图通过。

给审者当前工件和原始证据，不提供期望 PASS。平台无法开 fresh agent 时使用真实的同族交叉审查，披露上下文及模型作者角色，不能称外部或零上下文。争议记录位置、证据、影响、最小修复，并由原审者回审。

源文件变化导致旧哈希失效，即使图本身没变也不能直接重写旧回执。可以保存新限定复核：证明图字节和实际图注未变，重读相关语境并绑定现稿；说明继承与新增检查范围。PDF 重编后，逐页图像同像素只可支持继承已实际完成的版面检查，不能推出新数字或数学结论通过。

论文修订完成不等于数模方案的物理真实性、连续全局最优性或完整实验重跑。源码 ZIP 与完整实验支撑包分开命名；打包应从解压目录实际复编译，并核对其 PDF 与被审版本一致。
