# 变量与假设设计模式

变量命名优先使用简洁符号并配中文含义。假设需要同时写“为什么可以这么简化”和“可能造成什么偏差”。约束应区分硬约束、软约束和数据可验证约束。

## 假设分级

- **题目给定**：原文或附件明确给出，只需引用位置。
- **机理近似**：如忽略阻力、刚体、稳态，需要量级或文献依据。
- **统计假设**：独立、分布、同方差、删失机制，需要诊断。
- **计算假设**：离散步长、截断范围、搜索边界，需要收敛/边界检查。
- **情景假设**：政策、价格、概率，需要来源与压力测试。

每条假设记录 `id / statement / rationale / affected_equations / validation / failure_effect`。决策变量、状态变量、外生参数和观测量必须分开；同一符号不能跨问题改变含义。
