# 赛题拆解参考指南

拆题时先回答“谁、在什么条件下、优化或判断什么、输出什么”。对每一问分别记录输入、输出、约束、可用数据和可能模型族。隐含约束必须标注为推断，不能写成题目明示条件。

## 每问最小记录

| 字段 | 要回答的问题 |
|---|---|
| 对象 | 谁或什么系统？空间/时间范围？ |
| 输入 | 题干常量、附件字段、外部数据、可控量 |
| 输出 | 数值、排序、路径、策略、轨迹、文件模板？ |
| 目标 | 估计、解释、预测、优化、检验还是模拟？ |
| 约束 | 物理、逻辑、资源、时间、格式和竞赛规则 |
| 依赖 | 本问是否使用前一问结果？误差如何传播？ |
| 验证 | 有无已知值、极限、小规模或外部数据？ |

特别标记单位换算、附件坐标系、时间基准、缺失文件和题目要求的精度。不要把“可考虑”写成“必须”，也不要在选模型之前改写题目目标。
