# 数据清洗检查清单

检查文件编码、字段含义、单位、缺失、重复、异常值、时间顺序、类别取值、目标泄露和样本量。任何删除、填补、截尾都需要记录理由。

## 处理顺序

1. 保存原文件，记录文件名、工作表、编码、行列数和哈希（正式任务）。
2. 核对字段、单位、主键、时间和题目附件说明。
3. 区分真正缺失、结构性不适用、零值和解析失败。
4. 异常值同时看规则边界、IQR/稳健统计和业务/物理含义，不自动删除。
5. 去重前定义重复键；同一对象不同时间不是重复。
6. 所有插补、截尾、合并和类型转换形成 `cleaning_log.csv`。

目标泄漏检查优先于模型：任何由未来、标签、答案或完整数据拟合得到的字段都不能作为在线特征。时间、对象、批次和视频数据要保留分组字段供后续切分。
