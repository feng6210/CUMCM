# 统计推断与数据泄漏门

## 一票否决项

- 用完整数据做特征选择、标准化、重采样或阈值选择后再报告“测试集”结果。
- 同一个体、企业、设备或视频的记录同时出现在训练与测试中。
- 时间序列随机打乱后宣称能预测未来。
- 把训练集指标、交叉验证最优值或二次调参后的测试集指标当成独立泛化证据。
- 在未说明抽样设计、分母和区间时报告“准确率很高”。

## 按数据结构选验证

| 数据结构 | 验证方式 |
|---|---|
| 独立同分布样本 | 分层留出或嵌套交叉验证 |
| 同一对象重复测量 | GroupKFold / 留对象验证 |
| 时间数据 | 滚动窗口或时间外推验证 |
| 小样本二分类 | 重复分层交叉验证并报告区间 |
| 类别极不平衡 | PR-AUC、召回、特异度、校准与成本 |
| 生存/删失 | C-index、时间依赖指标、校准与删失机制说明 |

2020 C 国奖作者公开仓库明确指出比赛阶段模型曾在全数据上评估，而非独立测试集。这个反例说明“获奖论文”只能作为思路来源，不能替代验证审计。所有重采样必须只在训练折内部完成。
