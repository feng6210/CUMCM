# 动态模型选择与验证

先问四件事：状态是否连续、时间是否连续、是否有瞬时事件、决策是否影响下一阶段。连续时间连续状态通常用 ODE/DAE；离散时点用差分或状态空间；规则触发用事件模拟；多阶段决策用动态规划或最优控制。

## ODE/动力学最小验证集

1. 单位与符号方向。
2. 初始条件和边界条件。
3. 求解器、区间、容差/步长。
4. 半步长或更严格容差后的结果差异。
5. 方程残差、守恒量或已知极限。
6. 参数扰动与结论稳定区间。

## 动态规划最小契约

`state -> feasible_actions -> transition -> stage_reward -> terminal_value`。如果采用剪枝或状态压缩，必须说明被合并状态为何具有相同未来价值；如果采用记忆化搜索，键必须覆盖所有影响未来的变量。

国奖案例启示：2022 A 题不仅求受迫耦合振动的数值解，还分析刚性、数值阶与参数最优区间；2020 B 题通过状态转移、剪枝和记忆化搜索降低组合爆炸。新版流程要求把这些验证作为必选项，而非论文末尾的装饰。
