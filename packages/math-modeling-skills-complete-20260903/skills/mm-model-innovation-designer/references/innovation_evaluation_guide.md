# 模型创新评价指南

## 创新等级

| 等级 | 含义 | 能否作为核心创新 |
|---|---|---|
| L0 | 换名称、换库、换图表、无机制解释的参数调整 | 否 |
| L1 | 合理工程适配，如标准化、缺失处理、求解器配置 | 只能作为实现改进 |
| L2 | 针对题目结构改造特征、约束、状态或验证方案 | 可作为应用创新候选 |
| L3 | 提出可验证的新耦合、新目标、新状态转移或混合求解框架 | 可作为核心创新候选 |
| L4 | 具有普适理论或方法贡献，并有查新、推导和跨任务证据 | 需要严格研究级证据 |

等级表示证据要求，不表示获奖概率。没有对照实验的 L2—L4 只能叫“创新设想”。

## 六类创新位置

1. **机理**：补入守恒、几何、因果、动力学或行为规则。
2. **表示/状态**：构造充分状态、图结构、事件、时空或多尺度表示。
3. **目标/约束**：把现实边界、风险、公平、鲁棒性或多目标权衡写入模型。
4. **求解器**：利用问题结构做分解、剪枝、松弛、混合全局—局部或代理加速。
5. **不确定性/验证**：加入误差传播、稳健性、反事实、外推检验或独立复算。
6. **交付**：让模型输出满足决策、附件、复现和审计契约；它可增强作品，但不能替代模型创新。

## 强制证据卡

每个创新点回答：痛点、改动、机理、证据、风险和回退。等级只用于定义证据要求，不能替代对照、消融或专业判断。
