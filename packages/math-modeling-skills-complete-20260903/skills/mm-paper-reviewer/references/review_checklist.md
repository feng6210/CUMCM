# 建模论文审稿清单

先检查会改变答案、可行域和结论的 P0/P1，再检查叙事和审美。

## 一、题意语义与数学目标（最高优先级）

- 逐问对照题面原始表述与 `PROBLEM_SEMANTICS.yaml`：目标函数、集合并/交、时长计数、资源复用、多目标聚合是否一致。
- “总、同时、分别、联合、综合、至少、最多、每个、任一”等词是否被静默解释成方便求解的形式。
- 是否加入题面没有的“一资源只服务一个目标”“不同目标不可共享”等约束；若是近似，是否标明为假设并分析影响。
- 题目目标是否在摘要、模型、优化代码、结果表和结论之间漂移。
- 若两种合理解释会改变最优解结构，是否在求解前裁决；不能用写作措辞事后修复。

## 二、求解质量与外部击穿

- 是否先有最小正确基线，还是直接上复杂启发式。
- 搜索内核和正式 evaluator 是否分开；最终数字是否由正式 evaluator 重算。
- 约束是否逐项按原始变量重算，而不是只看 solver `success`。
- 多种子稳定只说明内部稳定，是否被误写成“已覆盖主要盆地/接近全局”。
- 用户提供优秀论文、公开策略或题目样例时，是否实际映射进自己的 evaluator；不能只比较原文报告数字。
- 外部可行解若领先超过容差，是否把“最佳/稳定最优”降级并返回求解，而不是用内部 gate 抵消反例。
- MILP gap 0 是否只被解释为有限候选库/离散网格上的最优，而不是连续全局最优。
- 求解器复杂度是否对应真实瓶颈；是否存在 DE+PSO+SA+GA 等无机制堆叠。

## 三、叙事冷审查

- 是否存在真实的分问依赖与共享模型内核，还是把多个小论文机械拼接。
- 共享坐标系、数据变换、动力学、几何判据或评价规则是否只定义一次；重复推导是否掩盖后续模型增量。
- 每问是否闭合“任务与难点—输入/继承—模型增量—求解与停止—精确结果—必要验证与边界”。
- 问题分析是否给出数学对象、难点、路径和判据，而不是重复问题重述。
- 摘要是否按分问回答问题，模型名和算法名没有堆叠成摘要主体。
- 图后是否解释现象、模型内机理和设计含义；没有识别证据时是否把推断写成了现实因果。
- 摘要/表格的舍入是否来自同一原始结果；对照的时间窗、初值、样本集合和聚合方法是否一致。不同窗口的差不能标为纯求解器误差。

## 四、Figure planning / 图表冷审查

- 不按“每问至少 N 张图”打分；只检查是否解决真实读者障碍。
- 复杂物理/几何/受力/case 是否有必要的二维机制图，还是只给公式+验证曲线。
- 模型从单主体升级到多主体、多资源、多阶段时，是否需要协同结构、时间区间或空间关系图。
- 每张图是否有明确 `reader_takeaway`；删除后若不影响理解/判断，应删或移附录。
- 精确值是否优先由表格承担；图和表完全重复时是否删其一。
- 验证图是否真正影响结论；完整多种子、微小步长差、后端 audit、版本谱系等次级诊断是否挤占正文。
- 算法流程图是否包含真实分支、停止条件和输出；章节目录式流程图不算机制图。
- 三维是否表达真实空间或参数关系并提供投影/切片/精确值；用户选鲜明样式不算缺陷，不能以固定低装饰偏好覆盖用户意图。
- 多面板在最终论文宽度是否可读；颜色、实体、线型是否跨图一致。

## 五、竞赛正文 vs 工程审计

`competition_compact` 中重点检查：

- 是否大量出现 `G4/G5/PASS_RESTRICTED/incumbent/hash/manifest/backend_report` 等内部工程术语。
- 若这些术语不改变数学结论，是否已经改写成读者可理解的“多初值稳定性”“有限候选库最优”“连续复算”等数学含义，并把原始审计信息移到支撑材料。
- 是否存在“每个失败版本都在正文讲一遍”的版本谱系泄漏。
- 正文是否仍然以“问题 → 模型 → 方法 → 结果”为主线。

`research_audit` 可保留更多复现细节，但仍不能遮蔽科学主线。

## 六、风险等级

- **P0 致命**：未答题、目标语义错、目标方向错、资源计数/集合运算错、数据/标签泄漏、硬约束未满足、结论与结果相反、伪造结果。
- **P1 高**：模型前提严重不满足、统计切分错误、数值未收敛、外部已知可行解击穿“最佳”声明、启发式冒充全局最优。
- **P2 中**：基线弱、敏感性不足、单位/符号不清、图表无法回溯、竞赛正文过度工程化导致模型主线不清。
- **P3 低**：措辞、图形样式和非关键排版。

先检查 P0/P1，再审美化。每个问题写出位置、证据、影响和最小修复；没有代码/数据支撑时只给“无法核验”，不替作者补造结果。

## 七、版面与修订证据

关键词整行粗体及分问选择性强调按模板检查，不宣称官方强制。检查标题层级、符号表列宽/单位、完整段落后的浮动体、跨问浮动、孤标题、小字图注和代码孤尾。正文与附录分开计页；完整代码和影响结论的失败不能因美化而删去。实际打开最终 PDF 后给位置，不能用编译成功替代阅读质量。

审者记录真实身份、被审工件及贡献关系；同族交叉审查不冒充外部/零上下文。改稿前后保留源与输出绑定；需要继承视觉检查时证明对应页面图像一致，并明确继承的是已实际完成的版面检查而非数值语义。
