# 优化模型选择

| 结构 | 方法 | 最优性证据 | 主要风险 |
|---|---|---|---|
| 线性连续 | LP | 求解器状态、对偶/残差 | 目标方向和单位错误 |
| 线性离散 | MILP/CP-SAT | gap、界、时间限制 | 可行但未证最优 |
| 光滑非线性 | NLP | KKT/残差、多初值 | 局部最优、缩放 |
| 多目标变量决策 | Pareto、epsilon 约束、目标规划 | 非支配性、权衡曲线 | 权重遮蔽非凸前沿 |
| 固定备选方案评分 | 加权评分/TOPSIS | 权重敏感性 | 不是约束优化 |
| 随机参数 | 情景/机会约束/CVaR | 样本外可行率 | 未来信息泄漏 |
| 区间不确定 | 鲁棒优化 | 最坏情形可行 | 过度保守 |
| 非凸/黑箱/组合 | 精确小规模基线 + 启发式 | 多种子、下界/上界 | 误称全局最优 |

所有脚本输出都要用原始目标函数重算目标值，并逐项检查约束。求解器 `success`、`optimal` 或停止码必须连同时间限制、gap 和容差解释。固定方案的加权排名不能命名为“多目标优化”。
