# 优化模型选择与求解器升级

## 先判断结构，不先选“热门算法”

| 结构 | 首选基线 | 可升级方法 | 最优性/可信证据 | 主要风险 |
|---|---|---|---|---|
| 线性连续 | LP | 通常无需启发式 | 求解器状态、对偶/残差 | 目标方向和单位错误 |
| 线性离散 | 小规模枚举/MILP | MILP/CP-SAT、分解 | gap、界、时间限制 | 可行但未证最优 |
| 光滑非线性 | 多起点 NLP | SQP/IPM；必要时全局法 | KKT/残差、多初值 | 局部最优、缩放 |
| 低维非光滑/黑箱 | 网格/多起点局部 | DE/CMA-ES/PSO 三选一 | 正式 evaluator 重算、多起点 | 零平台、漏盆地 |
| 多目标变量决策 | 单目标极端点/epsilon 基线 | Pareto、epsilon 约束、目标规划 | 非支配性、权衡曲线 | 权重遮蔽非凸前沿 |
| 固定备选方案评分 | 简单排序 | 加权评分/TOPSIS | 权重敏感性 | 不是约束优化 |
| 随机参数 | 确定性名义情景 | 情景/机会约束/CVaR | 样本外可行率 | 未来信息泄漏 |
| 区间不确定 | 名义/极端情形 | 鲁棒优化 | 最坏情形可行 | 过度保守 |
| 连续+离散混合 | 小规模精确子问题 | 分解、路线/列生成、主从、连续修复 | 有限主问题 gap + 连续复算 | 把有限库最优误称全局最优 |
| 昂贵黑箱 | 低预算空间填充 | 代理/贝叶斯优化 | 独立复算、留出/重复评价 | 代理偏差 |

## 求解器升级梯子

每次升级必须回答五个问题：

1. 简单基线具体在哪里失败？
2. 失败是维数、非凸、离散组合、昂贵评价、随机性还是在线时限导致？
3. 新求解器针对该瓶颈的机制是什么？
4. 新增了什么超参数、近似和验证负担？
5. 如果升级失败，能否回退到已验证基线？

没有明确答案时，不新增 DE+PSO+SA+GA 等算法堆叠。

## 搜索内核与正式 evaluator

允许为了速度使用粗网格、近似几何、代理模型或离散时间格发现候选，但必须显式区分：

```text
search kernel -> candidate discovery
formal evaluator -> hard constraints + official objective + exact/final recomputation
```

论文主结果只能来自正式 evaluator。搜索内核值只能作为搜索诊断。

## 外部挑战

若有合法外部可行策略，把它映射进当前正式 evaluator。外部策略领先当前 incumbent 超过预设容差时：

- 多种子内部稳定证据仍可保留，但只说明局部稳定；
- “预算内最佳/稳定最优/近全局”声明必须降级；
- 返回求解阶段扩大搜索或解释模型口径差异。

不同目标、不同物理判据或不同资源计数口径的原文数字标记 `INCOMPARABLE`，不能直接比较。

所有脚本输出都要用原始目标函数重算目标值，并逐项检查硬约束。求解器 `success`、`optimal` 或停止码必须连同时间限制、gap 和容差解释。固定方案的加权排名不能命名为“多目标优化”。
