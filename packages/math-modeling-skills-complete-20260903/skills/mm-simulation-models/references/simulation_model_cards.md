# 仿真模型卡

蒙特卡洛用于随机输入下的结果分布；排队模型用于到达、服务和等待系统；离散事件仿真用于状态随事件跳变的系统；灵敏度分析用于判断参数变化对结论的影响。

## 最小实验设计

1. 给出状态、事件、时间推进和随机分布的现实来源。
2. 固定并记录随机种子；多种子运行而不是挑最好一次。
3. 报告样本量、均值/分位数、Monte Carlo 标准误和置信区间。
4. 排队/稳态系统先检查稳定条件与预热期；`lambda >= mu` 的 M/M/1 无稳态。
5. 用闭式解、极限情形或简化系统交叉验证。
6. 逐步增加重复次数，检查目标指标是否收敛。

仿真产生的是给定模型和输入分布下的结果分布，不会自动证明这些分布或行为规则真实。
